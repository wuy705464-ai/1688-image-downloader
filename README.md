# 1688 商品图片批量下载器

这是一个 Tampermonkey（油猴）脚本。在任意 1688 页面右上角显示操作面板。

## 一键安装

[点击安装 1688 商品图片批量下载器](https://raw.githubusercontent.com/wuy705464-ai/1688-image-downloader/main/1688_image_downloader.user.js)

## 当前规则

- 输入 1688 商品详情链接：只读取商品页左侧主图缩略图栏，跳过第 1 张，保存第 2～5 张原图链接。
- 默认仅保存图片链接，不下载图片；可在面板切换为“保存链接并下载图片”。
- 输入直接图片地址：每条地址保存 1 个链接；下载模式下同时下载图片。
- 支持直接粘贴多行链接，也支持导入 `.txt` / `.csv` 文件。
- 自动保存任务和下载进度；页面跳转后继续执行。
- 每处理完一个链接，随机等待 7～10 秒再处理下一条；倒计时会显示在面板中。
- 检测到安全验证时自动暂停，手动完成验证后可继续。
- 同时保存商品 ID、标题、价格、起订量、店铺或公司名、原链接和图片地址，可导出 CSV 商品表。
- 导出的 CSV 中，图片 2～图片 5 分别写入独立列。
- 下载模式的文件名使用“商品 ID + 商品标题 + 图2～图5”，便于和商品表对应。

## 安装

1. 在浏览器中安装 Tampermonkey。
2. 点击上面的“一键安装”链接，在 Tampermonkey 页面确认安装。
3. 打开任意 `1688.com` 页面，在右上角面板中导入链接。

如果选择“保存链接并下载图片”，建议关闭浏览器的“每次下载前询问保存位置”，否则连续下载时会重复弹窗。

## 链接文件示例

```text
https://detail.1688.com/offer/123456789.html
https://detail.1688.com/offer/987654321.html
https://cbu01.alicdn.com/img/ibank/example.jpg
```

同一链接重复导入时会自动去重。

## 验证

- JavaScript 语法检查通过。
- 商品页模拟检查通过：跳过首图、最多下载 4 张、商品基本信息提取、CSV 导出。
- 直接图片地址的链接保存检查通过。

1688 页面会不定期改版；如果真实商品页出现字段或图片遗漏，请提交对应商品链接用于适配。
